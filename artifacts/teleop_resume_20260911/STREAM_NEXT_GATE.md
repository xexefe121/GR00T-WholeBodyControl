`gear_sonic/utils/g1_true23_student_packets.py` atomically admits synchronized original-native BFM fields, retargeted-native residual fields, and unchanged original29 task positions/quaternions. Canonical float64 fields are required, preserving the exact derivative arithmetic used by frozen features. Accepted samples use immutable bytes-backed arrays and scalar clocks. The38-sample FIFO retains the actual preceding sample across consumption, so the first task derivative of every sliding window remains correct. Only an explicit final packet permits a short final window. Sequence/epoch, source/receive clocks, stale arrivals/timeouts, invalid values/quaternions and buffer overflow latch faults. Rearm is an explicit input-epoch operation; the caller must separately verify physical standing and retain all physical/action history.
