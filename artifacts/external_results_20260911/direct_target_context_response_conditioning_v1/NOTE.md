# Saved response-loss conditioning evidence

Equal averaging over 54 cells balances row and axis counts; it does not balance the scale of the six feedback tasks. `full_state_loss` squares normalized endpoint-minus-center target error and has no radius or teacher-energy divisor. In a smooth unclipped neighborhood, both the target change and prediction change are proportional to radius, so squared error and its parameter gradient scale approximately with radius squared. Different physical units and clipped teacher maps prevent interpreting radius alone as difficulty.

The saved target energies provide a direct scale comparison: the zero-response baseline is about 3.27e-5 for root position, 3.39e-5 for joint position and 3.35e-5 for joint velocity, versus 4.33e-4 for root linear velocity and 3.54e-4 for root angular velocity. The largest/smallest group ratio is 13.24. The latter two groups contribute roughly 62% of the causal response loss despite each being slightly better than their zero-response baselines. Three lower-energy groups remain 1.78–2.07 times worse than zero response. Their poor relative feedback can therefore be obscured by the existing absolute-error objective.

Exact float32 feature collapse is ruled out for the generated corpus: generation rejects equality to each center and opposite-sign equality; completed independent data review found all 367570 model inputs unique with no target conflicts. This does not establish good conditioning or large feature-space separation. No final group-gradient norms, gradient cosines or normalized feature-displacement condition numbers were measured in this analysis.

Convergence also remains unresolved. The causal last-500 sampled means still improve against the preceding 500: nominal about 1.18%, full-state response 0.81%, physical 0.79%. The learning rate is falling, and sampled full-state rows differ by update; these windows do not demonstrate convergence or a width limit. The common lower learning rate substantially reduced the earlier reset spike, but second-update nominal loss is still about 2.73 times first-update loss in the causal condition. Initial gradient geometry from the earlier model cannot substitute for current final gradients.

If canonical behavior fails, a more defensible next controlled hypothesis is feedback-loss scale balancing on the existing fixed neighborhoods, keeping context, architecture, labels and ordinary endpoint rules fixed. For example, fixed group weights proportional to inverse saved zero-response energy would directly expose relative feedback failures; scaling each by the six-group mean energy preserves the old zero-response baseline's overall magnitude. These illustrative weights are reported, not selected. They do not guarantee equal gradient norms, favorable gradient directions or stability. A raw division by physical radius squared would additionally mix meters, radians and rates and would need a separate explicit unit convention.

Current evidence supports a loss-conditioning concern and measured context utility. It does not establish that conditioning is the sole failure cause, that more epochs solve it, or that larger capacity is required. No model, gradient, optimizer or native calls were made.
