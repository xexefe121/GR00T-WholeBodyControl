# Direct-target evaluation adapter — source preparation only

This package prepares the selected 1,000→256 ELU→256 ELU→23 linear normalized absolute-target head for one future canonical walk003 evaluation. It has not created a model session, run a controller or native step, launched a witness, fitted weights, installed a runtime, or generated an execution binding. Actual final5000 weights, data/fit/source/export review subjects and a separately selected launch are still required.

The direct input is exactly original features `[0:52] + [75:1023]`: measured joint position/velocity, root angular velocity, projected gravity, heading-relative root linear velocity, height and the unchanged eight received-goal blocks. `DirectFeatures` constructs these 1,000 values directly from measured qpos/qvel and prepared goal data. No previous target, raw action, history, BFM base, frame ID or absolute clock value enters the head. Frame number only selects the goal window. Original preceding-sample derivatives, offsets through37 and EOF clamping remain unchanged.

The head receives float32 features; its embedded normalization and MLP return float32 `normalized_target`. Output math is explicitly:

```text
delta_f64  = existing_joint_span_f32.astype(f64) * normalized_target_f32.astype(f64)
raw_f64    = default_q_f64 + delta_f64
target_f64 = clip(raw_f64, unchanged_native_limits_f64)
```

The span is the existing rounded float32 artifact, promoted to float64; the exact float64 native-bound difference is not substituted. No multiplication or subtraction is performed in float32 before promotion. The final clamp handles native-limit rounding. In learned trace rows `base_target` means the fixed default position and `delta` means the full affine displacement, with no BFM-base computation. `normalized_head` records the actual normalized output; BFM rows use explicit zeros because the head is not called.

Timeline phases govern the future run: original yaw2 BFM controls0–249, direct learned control250–1268, then original yaw4 BFM from1269. The main lifecycle retains1569 controls, followed by a separate continuous250-control hold only if the main physical run completes. All819 source controls and reference indices remain intact. The clock-foundation draft is not connected.

During the learned phase the actor and backward BFM sessions are guarded against any call. Only one head call is allowed per successful learned proposal. Measured BFM terms/history are maintained for the terminal transition, but never enter the learned head. The exact original `before_update` operation runs on a staged history copy with the incoming previous action; proposal/first-input/first-output gates must pass before the command, history and outgoing action commit immediately before native execution. Learned outgoing previous action is the original inverse mapping of the **actually clipped target**, float32 and without a ±5 clamp. Startup and terminal retain the original raw-BFM-plus-zero arithmetic, including floating-point ordering and signed-zero behavior.

Every actor/backward/head attempt and return is counted per phase, with current-call inputs/outputs preserved before validation. Failed inference or parity checks retain the pending proposal and before/after history without committing a command. Native exceptions preserve the selected command, full state, unchanged last expected clock and completed samples; strict failures preserve every returned native sample. The original native PD expression and `assess`/`get_state` functions are unchanged. Initial291 values must exactly match the canonical startup trace before its first step; no recorded state is injected at query250 or later.

The actual first learned input must equal reduced query250 labels and center2038 byte for byte. One future separately counted WSL batch1 head witness uses that same input. The evaluator's first normalized output, promoted pre-clamp raw proposal and target must match that witness exactly before command execution. Both use ORT1.23.2, one thread, sequential CPU execution; the evaluator checks its actual binary hash against the witness and requires WSL NumPy1.26.4. Missing real final files/reviews/bindings stop before model creation. This preparation creates no placeholder binding or executable launcher.

The in-memory startup250 parity gate executes before any learned row, so its original delta dtype remains byte-exact. A later completed mixed-phase trace promotes the entire `delta` array to float64.
