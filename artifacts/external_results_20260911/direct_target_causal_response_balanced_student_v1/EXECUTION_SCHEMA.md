Actual request is training_request.json. The immutable source_snapshot_v1 copies the reviewed 25-file prepared map exactly. training_frozen_inputs.json binds source, inherited qualified data/runtime files, all consumed saved causal outputs/context files, current proposal/source/math/semantics reviews and execution helpers. training_clearance_draft.json is approved=false; only root may write the actual approved clearance after its concrete review. No process is dispatched by preparation.

run_fit_durable_v1.ps1 requires exact clearance SHA. One CreateNew running.lock in fit_process_v1, hidden GPU Python child, captured process handle, known raw exit. The wrapper checks ordinary71000/AdamW6000, fixed counts and numerical completion, then records prerun/postrun pin maps and exit.json with raw_python_exit_code, exit_code, exit_known, wrapper/child IDs. Monitoring uses read_fit_progress_v1.ps1 with FileShare.ReadWrite|Delete.

verify_completed.py performs only saved checks after both actual PIDs are absent. It validates exact full launch pin membership and values, current hashes, counters and all output manifests. owner_completion_verification.json keeps accounting_passed separate from completion_passed and numerical_completion_passed. It records raw_exit_known, raw_python_exit_code, exit_code, processes_absent, all_postrun_pins_exact, expected_pids and process_exit SHA.

On success, direct_subject_sha256 has fit_report, checkpoint, head, normalization, training_manifest, training_request, export_manifest, coefficient, energy_source, balance_source_review, source_checkpoint, source_fit_report, full_state_generation_request, full_state_generation_report, full_state_data_audit, full_state_data_owner, shared_manifest, context_alignment and process_exit.
