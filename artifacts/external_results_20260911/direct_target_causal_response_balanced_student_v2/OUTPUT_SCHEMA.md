# Fixed ordinary71000 output schema

The single condition writes to `fit/`, with condition `causal`. Nothing is written there during source preparation.

`fit/shared/` contains byte copies of the qualified prior shared normalization, nominal/center/physical context arrays, data identities, context alignment and 3000×864 center/axis schedule. The old shared manifest is copied as `source_output_manifest.json`; the new `output_manifest.json` and `reused_inputs.json` bind source paths and copied hashes. No new moments, context rows, labels or sampler draws.

`initialization.pt`: actor_state (six learned float32 tensors), optimizer_state (six complete warm AdamW states at step3000 and unchanged source param-group dictionary), rng_after_restoration, feature_mean/std, condition, ordinary_start_step68000, optimizer_start_step3000, source_checkpoint_sha256. `restoration.json` confirms these exact comparisons and gives initial_GPU32 vs source final_GPU32 per-corpus byte_equal/max/RMS preclamp error. Admission remains 1e-5 rad, not a new byte gate.

`used_centers.npy`: int32(3000,864). `used_axes.npy`: int8(3000,864), uncommitted rows -1. `training_progress.npy`: float64(committed_updates,6), columns **nominal, balanced_full_state, physical, balanced_total, learning_rate, preclip_gradient_norm**. `original_objectives.npy`: float64(committed_updates,2), **original_full_state, original_total**. `nominal_cell_losses.npy`: float64(N,15). `full_state_cell_losses.npy`: original float64(N,54). `balanced_full_state_cell_losses.npy`: weighted float64(N,54). `physical_cell_losses.npy`: float64(N,9). All cell order and fixed denominators unchanged. Failure state reports committed loss rows separately from optimizer returned/synchronized calls and six actual step counters.

`student_head.pt` is saved immediately after all3000 updates: ordinary_final_step71000, optimizer_step6000, fresh_optimizer=false, complete actor/optimizer/RNG/norm/span/default/limits, coefficient and response group weights/rule, source checkpoint hash. `optimization_completed.json` marks optimizer completion before export qualification.

For each backend `initial_GPU32`, `final_GPU32`, `CPU64`, `GPU64`, `ORT64`, predictions are float32: `BACKEND_nominal.npy` (9904,23), `BACKEND_full_state.npy` (354612,23), `BACKEND_physical.npy` (3054,23). Each backend gets exactly1437 calls over separate corpus batches of256. `diagnostic_calls.jsonl` retains attempted rows and returned/synchronized/verified status per call.

`BACKEND_metrics.json` retains original names/values: nominal_objective, full_state_objective, physical_objective, weighted_objective=N+lambda*originalF+P, original54cells/odd/even/zero-response/first24/clipping. Add balanced_full_state_objective, balanced_weighted_objective=N+lambda*balancedF+P, balanced_full_state_cells (54 weighted cells), weighted group/odd/even/zero-response summaries. `optimization_objective` explicitly names balanced_weighted_objective. Final report carries all five metrics records.

`student_head.onnx` uses the same ordinary71000 float32 parameters promoted exactly to float64 normalization/linear/ELU, public input/output float32. `promoted_parameters.json`, `export_parity.json` and `drift.json` bind exact promotions, nine CPU64/GPU64/ORT64 preclamp comparisons and nine complete float64 drift arrays vs final_GPU32, with clipping changes. Export tracing uses zero forwards. Original1e-5rad gate remains fixed.

`report.json`: completed, optimization_completed, final_export_diagnostics_completed, numerical_gate_passed, export_parity_passed; ordinary_start_step68000, ordinary_final_step71000, additional_updates3000, optimizer_start_step3000, optimizer_step6000, fresh_optimizer=false; condition causal, features1323; fixed coefficient/weights/rule; counts; metrics; checkpoint/ONNX/request/frozen/shared/output manifest hashes, source checkpoint and teacher energy source hashes; all_frozen_inputs_unchanged, checkpoint_selection=false. `output_manifest.json` hashes immutable output files including ledgers, loss arrays and metadata. A failed numerical gate does not erase the ordinary endpoint.

On failure retain failure.json, failed_active_evidence.npz, failed_state.pt with resumable=false, all memmap prefixes, six optimizer counters, optimizer started/returned/synchronized flags, completed update count, committed loss prefix and final rehash result. Setup failures before any model forward have an explicit zero-call setup_failure.json. No automatic retry. Process/owner metadata will be concretely bound only after source review and root selection.
