## Sidecar checks

The decoder independently requires reviewed signed64 row layouts, native byte order/item size, exact byte counts and metadata fields. It verifies phase/tick/control/thread identities, increasing phase order, parentage, inclusive capture/verify child placement, local wall brackets, same-thread paired CPU/wall order and successive root-span order. It rejects skipped/duplicated roots, impossible attempt counts, wrong epoch deadlines, saved wake before wait completion, saved finish before verification ownership, and append before the original finish timestamp.

Every committed actual sample requires its reached native/capture/verification scopes. Extra terminal scopes may record a call which had not started or returned when a fatal interruption arrived. Counts remain attempt/returned/captured/verified separately. One outstanding terminal discrepancy requires a failed root scope and matching reached operation, actual bounded count direction, and already-owned adapter capture/assessment evidence where credit differs. A completed capture/verify scope cannot explain missing foundation ownership. No new native or verifier credit is inferred.

The supplemental last actual capture, when available, is independently decoded, matched to foundation bytes where both exist, and checked through the original pure full291/PD/force/warnings/repeated-time/strict predicates. A strict state can be measured as valid even when the original verifier did not return; the report explicitly keeps `new_verification_credit=0` and `full_scope_credit=false`. A returned step without a captured state remains a known actual return with an unavailable state, never complete physical evidence.

GC rows retain independent start/stop pairs, generation, owner thread, partial fields, explicit denials and unfinished pairs. Foreign-thread `inside_probe=1, active_span=-1` is recorded as overlap, not proof of interrupting the sampled thread. Completed pair wall/thread/process order is checked locally; callback timing is not compared against a global threshold that would reject valid reentrancy.

Epoch-armed counters must precede spans; final span/hook counters equal the outside-loop exit receipt. GC may append during the first exit journal/detachment, so its recorded count may extend that exact prefix. A new post-exit probe fault must refer to a later GC record or callback-registry failure. Complete instrumentation requires detached callback, no probe/hook fault, no pending spans/open generations, intact file writes, and unchanged GC enablement. Hard-timeout, missing final stage, nonzero/unknown raw exit and full-scope checks remain the original independent stage gate.

## Results and limits

The report adds `timing_sidecar` alongside existing physical, command, timing, process and protocol results. Per-phase records expose up to ten largest complete wall brackets and matching thread/process CPU deltas. Native-phase duration includes original essential call bookkeeping; root duration includes fixed wait; capture/verification durations include their ownership children. Nested phases cannot be summed as disjoint work. Process CPU includes other threads and may differ from thread CPU; wall-minus-CPU alone does not establish scheduler/GC causation.

Missing sidecar files require explicit writer-failure evidence and prohibit instrumentation qualification. Retained files are still hash/size/input-pin checked. When sidecars are unavailable, no terminal counter-gap proof is granted; an unsupported gap causes audit failure with preserved exception rather than fabricated completion. Completed sidecars with an ordinary strict/command/timing failure can still pass evidence integrity while overall qualification stays false.
