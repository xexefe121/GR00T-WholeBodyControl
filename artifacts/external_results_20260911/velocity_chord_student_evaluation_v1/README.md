`proposal_evidence.py` records raw `base_target + delta` proposals and the inverse normalized action of the actual clipped target. These values are diagnostic only. The controller deliberately retains the original raw combined-action prior and history, including its known discrepancy when native target clipping occurs. Native parameters, strict 2 ms limits, phase/reference clocks, actor math and policy settings are unchanged.

Every attempted precontrol keeps the full 291-value integration state, actual prior and history. Policy/parity failures retain all returned session inputs/outputs and before/after controller history. Native limit failures retain their actual failing sample. A native call exception keeps completed samples and the attempted command separately, marks the attempted step unclassified, and exits without claiming completion. Empty failure traces retain their canonical trailing shapes and dtypes.

The selected additional activation witness runs exactly one WSL batch-one final-head call on immutable center row 2038, original dataset2/control250/source261. The canonical evaluator first reproduces the complete original BFM250 prefix, compares its actual query250 state/features/base/history/prior with the qualified label, and requires its first final-head output to match the WSL witness byte for byte before applying the learned command.

`freeze_final_package.py` accepts a configuration containing actual completed dataset, fit, source and export review paths and exact boolean pass fields. All reviews must bind their actual subject hashes. It refuses absent exports, incomplete fit gates, missing reviews, or existing bindings. No example or placeholder launch binding is supplied. `prepare_bound_launcher.py` runs the pure final gate before creating a process directory, then prepares the fixed WSL command and hidden durable wrapper. Neither utility launches a process. Durable wrappers use an exclusive creation lock, captured child handle, separate stdout/stderr/start/child/exit receipts and pre/post hashes. Incomplete main/hold, failed quiet, or failed transition parity returns nonzero.
